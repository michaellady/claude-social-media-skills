the gap is systemic: 172/217 (79.3%) long-form+live videos have no tags,
including both evergreen long-forms (uEposKmbFvY, H9HR4_Qz-Z0) and the

`update-tags` command (OAuth write scope) that can do this in seconds. So
re-pose the intervention with the tool that removes the human step, and a
hard three-strikes rule: execute `update-tags` by 2026-05-31 or retire the
tag thesis for good. This finally separates "the idea doesn't work" from
"we never tried it."

## h-2026-05-25-3: native A/B needs live-scale traffic

videos — title value is launch-window-bound. The companion problem: the
